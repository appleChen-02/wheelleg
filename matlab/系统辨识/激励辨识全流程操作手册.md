## 1. 出发点：无激励基线告诉了我们什么

以下数字来自 results/20260910_112017（**该数据采于减速比修复之前**，修复后须重采一次基线，方法完全相同）。

### 1.1 基线关键数字

| 项目 | 数值 | 含义 |
|---|---|---|
| 工作点 body_x | 实测 +0.394 m，参考 −0.5 m | 位置闭环稳态偏差 0.894 m（不进动力学，仅裕量问题） |
| 左/右 theta | 0.155 / 0.199 rad，参考帧 0.2705 | 持续闭环误差 −0.115 / −0.071 rad；左右不对称 2.5° |
| tail_beta | 实测 0.118 rad，参考 0 | 尾巴工作点偏离模型零位 |
| LQR 输出偏置 | 右髋 −2.64、左髋 +0.64、右轮 −0.057、左轮 +0.117、尾 −0.514 N·m | 模型误差被闭环以恒定偏置偿还 |
| 平衡前馈（模型） | 髋 +1.0113、尾 −1.4425 N·m | 名义模型的平衡输入 |
| 闭环波动 std | pitch 0.0028 rad、theta_L 0.0048、theta_R 0.0029、body_x_dot 0.0087 | 稳态"噪声底"，激励响应应显著高于它 |
| body_x 漂移 | +2.5e-4 m/s（带显著二次项） | 长实验会漂，单段建议 ≤120 s |
| 日志一致性 | command−controller−equilibrium−excitation RMS ~1e-8 | 日志分解链可信 |

### 1.2 解读：基线数字如何指导激励实验设计

1. **右髋 −2.64 N·m 偏置**是最大的模型误差信号。它意味着：右髋通道叠加激励时，直流工作点已经偏离模型平衡点很远，单边激励裕量被压缩——髋通道激励幅值必须从小起步。
2. **左右 theta 不对称（0.155 vs 0.199）**说明左右腿真实动力学不同。左右髋通道要**分别**辨识，不要指望一个模型管两边。
3. **波动 std 是"噪声底"**。激励幅值的效果判据：响应 std 至少达到噪声底的 3 倍，相干度才可能上 0.8。例如 pitch 噪声底 0.0028 rad，髋通道激励希望 pitch 响应 std ≥ 0.008 rad 量级。
4. **漂移 +2.5e-4 m/s**：60 s 扫频漂 0.015 m，可忽略；PRBS 若采 3 分钟漂 0.045 m，需要记录并在分析时注意（脚本自动用激励前稳态段定工作点）。

### 2.3 采集流程（一次实验的操作卡片）

1. **开机自检**：电池、遥控电量、地面平整无滑动、周围 2 m 净空。
2. **启动记录**：`py usb_data_logger.py --port COMx --outdir data/<日期>_<通道>_<幅值档> --save-mat`
   - **先启动记录，再进模式**！分析脚本需要 ≥5 s（建议 ≥10 s）的激励前稳态段来确定工作点，没有这段会降级并影响低频解读。
3. **（可选但推荐，第一次每通道先做）悬空测试**：编译期开 `LIFTED_UP`，把机器人抱起来跑一遍激励，只验证信号链（日志里 excitation 波形正确、电机有力矩输出、无异常报警），不下地。
4. **进入模式**：CH5 与 CH8 同时上档 → 扫频立即开始，60 s 后自动归零（SWEEP_FINISHED 置位），机器人保持在辨识模式由 LQR 维持。
5. **扫频期间**：观察 pitch 摆幅、是否位移过大、电机声音是否异常；手不离遥控。
6. **扫频结束后**：保持模式 10 s 以上再退出（给分析脚本留下激励后稳态段）。
7. **退出模式**，停止记录，检查 `data_quality`（丢帧率、饱和）。
8. 每个幅值档重复；同参数重复一次以验证可重复性。

### 2.4 安全规程与中止条件

出现以下任一情况，**立即退出系统辨识模式**（断激励最快路径）：

- |pitch 偏差| > 0.1 rad（约 5.7°）且趋势扩大；
- theta 偏离参考帧值 > 0.3 rad；
- body_x 位移 > 1.5 m 或撞到障碍；
- 实时日志 `motor_saturation_mask` 长时间非零（>1% 帧）；
- 电机异响、异味、温度异常。

中止后：该通道该幅值标记为"越界"，下一档实验幅值减半。

### 2.7 频响通用解读方法（本节是全文的方法论核心）

#### 2.7.1 可信范围三要素

一个频点上的 FRF 只有同时满足以下三条才可信：

1. 频点在激励频带内（扫频 [0.2,20] Hz；PRBS [0.2, 0.5/码元时间] Hz）；
2. 该频点 `coh ≥ 0.5`（最好 ≥0.8）；
3. 频点高于约 `2/窗长`（10 s 窗 → 0.2 Hz；低于此窗内周期不足，偏低频不可信）。

#### 2.7.2 相干度的统计含义

γ² = 输出方差中能被该输入线性解释的比例；估计偏差 ≈ (1−γ²)/nseg。nseg=10 时 γ² 读数低于 0.1 一律视为"无相关"。想要 γ² 判定误差 <±0.05 需要 nseg ≥ 30（约 3 分钟数据）——**扫频做诊断，PRBS 出正式数据**的原因之一。

#### 2.7.3 从 FRF 读四个物理量

**① DC 增益**（低频平台）：取可信频段最低 3–5 个频点的 |G| 均值。它是静态刚度/增益的直接度量，与名义模型对比最能暴露参数误差。

**② 共振频率 f_r**：|G| 局部峰。与名义模型对比：(f_r,实/f_r,模)² = 等效刚度或惯量的缩放因子。例：实测峰 1.8 Hz、模型 1.5 Hz → 模型惯量偏大约 44%。

**③ 阻尼比 ζ（半功率带宽法）**：峰 |G|max 两侧 |G|=|G|max/√2 处的频率 f₁、f₂，则 ζ ≈ (f₂−f₁)/(2f_r)。实测 ζ 明显小于模型 → 未建模摩擦/延迟。单峰且与相邻峰分得开时该方法才成立。

**④ 延迟 τ（相位斜率法）**：在幅值平滑衰减（无共振）的高频段对解卷绕相位做线性拟合 φ(f) = φ₀ − 360·τ·f，则 τ = −斜率/360。典型来源：CAN 发送 + 电流环 + 控制周期，合计 1–2 个控制周期（2–4 ms）。模型里必须显式补上，否则 LQR 高频相位裕度是虚的。

#### 2.7.4 线性度判定

同通道多幅值的 FRF 叠图（把每次运行的 frf_input_*.csv 画在一起）：

- γ²≥0.8 频段内幅值差 <10%、相位差 <5° → 线性；
- 大幅值时低频增益下垂、峰移位、出现新峰 → 越界，记下上限；
- **所有后续辨识实验幅值 ≤ 线性上限的一半。**

```c
                                                       // 12状态主导动态<3Hz，足够且对传动友好
#define SYS_ID_EXCITATION_AMP_TAIL      (0.1f)         // 用扫频确认的"线性上限的一半"
```

**注意**：PRBS 不自动停止，持续到退出模式。单次采集 2–3 分钟，用遥控切断。种子固定，重进模式序列完全复现。

### 3.2 分析

与分析扫频完全相同（脚本自动识别类型并按 PRBS 频带解读）。检查点：

- excitation_check 的 `prbs_pos_level_frac + prbs_neg_level_frac ≈ 1`、`hold ≈ 0.04 s OK`；
- 相干度因采集更长、功率谱平坦，应显著好于扫频；nseg 目标 ≥30。

### 3.3 单通道参数模型拟合

对每对"激励通道 → 主导状态"用频响数据拟合传递函数（需要 System Identification Toolbox）：

```matlab
S = load('frf_data.mat');                 % 阶段二运行结果
% 例：右髋 -> pitch
f  = S.f(S.valid(:) & S.f>=0.5 & S.f<=12);
G  = squeeze(S.G(9,1,:));                 % 9=pitch

```

判据：拟合的 T 频响落在 H1 曲线 ±（估计方差）内；参数物理上说得通（ζ、f_r、增益）。

## 4. 阶段三：全通道 MIMO PRBS → 12 状态空间辨识

### 4.1 实验设计

```c
#define SYS_ID_EXCITATION_INPUT_MASK    0x1FU   // 五通道同时，独立种子
```

- 各通道幅值 = 阶段二确认的安全值（预计髋0.2、轮0.1、尾0.1 N·m）；
- 采集 **2–3 次、每次 2–3 分钟**：第 1 次辨识，其余留作验证（换着用，防止过拟合）；
- 全程记录，进模式前先开记录（保留激励前稳态段）。

### 4.2 数据准备

```matlab

% 状态偏差 y：相对工作点（用 analyze_sysid_excitation 输出的 x_op_used）

```

### 4.3 ssest 流程

```matlab

            'n4Weight', 'SSARX', 'SearchMethod', 'lm');
% 阶次扫描：也试 nx = 8, 10, 14 —— 若 10 阶拟合度与 12 阶几乎相同，
% 说明有两个状态贡献极小（常见：yaw/yaw_dot 或 tail_beta_dot），如实报告
```

若 §2.7.3④ 检出明显延迟 τ：`ssest(..., 'IODelay', tau*250)`（按采样周期数）或在 B 上补延迟。

### 4.4 状态顺序对回

辨识出的状态顺序与固件定义（body_x … tail_beta_dot）**不会**一致。对回方法（按可靠度排序）：

1. 用频响匹配：辨识模型第 i 个状态对某输入的频响形状，与实测该物理状态的频响比对；
2. 用 A 的结构：如 pitch 对应的姿态通道应有积分关系（A 中 x_dot 行=1）；
3. 对回后用相似变换把 (Â,B̂) 化为与固件同序，并验证变换后频响不变。

**这一步没做，A、B 不能进 LQR。**

### 4.5 验证门禁（全部通过才算数）

| 检验 | 命令 | 门禁 |
|---|---|---|
| 留出仿真复现 | `compare(Zval, sys)` | pitch/theta/body_x_dot 拟合度 >85%，其余 >70% |
| 残差白性 | `resid(Zval, sys)` | 残差自相关在置信带内；**残留周期成分=有未建模扰动，禁止继续** |
| 频响交叉验证 | 叠画 sys 频响与 frf_data.mat 的 H1 | 在 γ²>0.8 频段内一致 |
| 稳定性 | `eig(sys)` / `pole(sys)` | 开环不稳定极点数量与物理一致（倒立摆应有一对右半平面/单位圆外极点），无异常高频极点 |

### 4.6 没有工具箱的替代路径

用 `frf_data.mat` 做频域加权最小二乘（输出误差法自写迭代），或特征系统实现法（ERA，对马库夫参数做 SVD）。可行但工作量大；**优先装 System Identification Toolbox**。

## 5. 数据 → 改进

### 5.1 差异清单（改进的施工图）

每个激励通道填一行，全部来自 §2.7 的读法：

| 通道 | 频段 | 症状 | 量化差异 | 物理假设 | 建议动作 |
|---|---|---|---|---|---|
| 右髋→pitch | 0.3–1 Hz | DC 偏低 ×0.6 | 增益差 40% | 重力前馈系数偏小 | 修 T0_coef 常数项 |
| 髋→theta | 全带 | 谐振 1.8 vs 模型 1.5 Hz | ×1.2 | 腿摆惯量偏大 44% | 修模型惯量参数 |
| 轮→body_x_dot | 高频 | 相位斜率 720°/100Hz | τ≈2ms | CAN+电流环延迟 | 模型加 ioDelay |
| 尾→tail_beta | 2 Hz | 实测 ζ=0.04 vs 模型 0.10 | 阻尼减半 | 轴承摩擦 | 模型加阻尼项；Q/R 留裕量 |

（表中数值为示例，以实际数据为准。）

### 5.2 Level 1：工作点与前馈修正（当天可完成，零风险）

1. **theta 参考修剪**：`SYS_ID_REF_LEFT_LEG_THETA = -0.115f`、`SYS_ID_REF_RIGHT_LEG_THETA = -0.071f`（= 实测均值 − theta_eq(0.18)=0.2705）。目的：消除持续 theta 闭环误差和相应 LQR 偏置；
2. **T0_eq 修正**：由基线计算各腿"实际需要的平衡力矩" = controller_均值 + equilibrium_均值（右：−2.64+1.01 = −1.63；左：+0.64+1.01 = +1.65）。**注意左右近似反号，两腿 Tp 符号约定可能是镜像的**（K 矩阵左右行互为镜像），先在悬空状态核对物理方向，再决定是把公共修正量加进 `T0_coef_Bipedal` 常数项，还是左右分开处理。左右不对称部分无法用共因子修正，如实记录为模型不确定性；
3. **尾巴**：`SYS_ID_REF_TAIL_BETA = 0.118f`（可选），或先查尾巴 DC 误差来源；
4. **body_x**：`SYS_ID_REF_BODY_X = 0.0f`（纯整洁性，不影响动力学）；
5. 改完 → 重编译 → **重跑无激励基线** → 检查 u_eq 偏置是否从 ±2.6 N·m 缩到 ±0.5 内、theta 偏差是否归零。旧基线作废。

### 5.3 Level 2：用辨识模型重设计 LQR

**原则：一次只改一件事。**

**第一步：原 Q/R + 新模型。** 用原 Q、R 配 Â、B̂ 重解 K，这样 K 的变化纯粹反映模型修正，效果可归因：

```matlab
[Ad, Bd] = c2d(Ac_hat, Bc_hat, 0.002);   % 或从 Ts=0.004 的辨识模型 d2c 后重采样
K_new = lqr(Ad, Bd, Q_orig, R_orig);
% 离线校核：新旧 K 的闭环极点对比；用录制的激励数据仿真新旧闭环的状态响应
```

**第二步（确认改善后）：动 Q/R。** 依据差异清单调整（如阻尼实测偏低的通道加大对应状态的权重），每次只动一项。

**部署的三个硬约束：**

1. **误差状态约定不能动**：`CalcLQR_Pro_Tail` 手写展开、`X0_OFFSET~X11_OFFSET`、yaw 的 WrapToPi、theta 误差含 theta_eq——新 K 必须按完全相同的误差定义使用；
2. **K 的腿长插值**：固件 K 系数是腿长多项式（`K_coef_Bipedal`，60行×6系数）。只辨识了 0.18 m 时，第一版**只在辨识模式（固定腿长）下用新 K**，其他模式保留旧系数。要全模式生效：在 3–5 个腿长点（0.14/0.16/0.18/0.20/0.22 m，须在 MIN/MAX 内）各做一轮"改 SYS_ID_LEG_LENGTH → 阶段三辨识 → 解 K"，再按原系数结构拟合多项式；
3. **上线次序**：悬空（`LIFTED_UP`，验证新 K 符号方向）→ 辨识模式（固定腿长+全日志，跑无激励确认 k_check 比例回到 1 附近：把新 K 系数填进 analyze 脚本的 `buildK`）→ 正常模式。

**鲁棒性校核**：对 Â、B̂ 做 ±20% 元素摄动，新 K 闭环极点保持稳定且阻尼比不塌；γ²<0.8 的频段视为 100% 模型不确定——新 K 的灵敏度函数峰值在这些频段不得高于旧 K。

### 5.4 Level 3：结构扩展（仅当诊断指向）

触发条件（满足其一才考虑）：主导带宽内出现**未建模谐振峰**且陷波解决不了（影响相位）；腿长/roll 耦合被证明是性能瓶颈。

18 状态/7 输入增量：状态加 roll、roll_dot、左右腿长及速度；输入加 F_left、F_right。辨识需打开 mask 的 0x20/0x40 位做腿轴力激励；必须先解决腿长 PID 与新 LQR 对 F 的重复作用。成本=重做一遍阶段一~三+全部改进，确认 12 状态已榨干再启动。

### 5.5 一次"改模型→改K"的完整循环清单

```
□ 差异清单定稿
□ 改 compute_lqr_0809 模型参数 → 重新出 A/B/theta_eq/T0/K
□ Level 1 参考与系数修正 → 重编译
□ 重跑无激励基线 → 偏置/工作点检查
□ 悬空验证 K 方向
□ 辨识模式无激励 → k_check 验证新 K
□ 单通道扫频复测 → FRF vs 新设计模型

```

## 8. 附录

### 附录A 常用公式速查

```text
H1 频响估计:        G(f) = S_yu(f) · S_uu(f)⁻¹      （多输入：矩阵式；单输入：标量式）
普通相干:           γ² = |S_uy|² / (S_uu · S_yy)
多重相干:           γ²_m = 1 − (S_yy − S_yu S_uu⁻¹ S_uy) / S_yy
相干估计偏差:       bias ≈ (1−γ²) / nseg
频率分辨率:         Δf = fs / Nfft（10s窗 → ≈0.1 Hz）
可信低频下限:       f_min ≈ 2 / 窗长
半功率带宽阻尼:     ζ ≈ (f₂ − f₁) / (2·f_r)，f₁/f₂ 为峰两侧 |G|=|G|max/√2 处
延迟（相位斜率）:   τ = −(dφ/df) / 360，φ 单位度、f 单位 Hz
谐振缩放:           (f_r,实 / f_r,模)² = 等效刚度比（或惯量比倒数）
峰值因子:           正弦 √2，PRBS = 1 → 同峰值下 PRBS 平均功率 ×2
MIMO 可逆性:        多通道输入须互不相关（PRBS 独立种子），否则 S_uu 病态
```
